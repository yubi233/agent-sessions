# ADR-002：设备身份与端到端加密

- 状态：Accepted
- 日期：2026-08-13

## 背景

单租户服务器需要管理设备和在线状态，但管理员默认不能读取会话正文、文件、diff 或工具参数。

## 决策

- 账号使用邮箱/密码完成服务器身份认证。
- 每台设备生成 Ed25519 身份签名密钥和 X25519 加密密钥。
- 首个 Android 设备为 owner/key-admin，批准和撤销后续设备。
- 每个 Project 或 Session 生成独立 DEK，使用 X25519 包装给授权设备。
- 内容使用 AES-256-GCM，HKDF 派生用途密钥；AAD 绑定实体、事件类型、revision 和 event_seq。
- Android 使用 Keystore，PC 使用系统 Keychain，Web 仅保存最小化的短期密钥材料。
- 恢复码用于恢复 owner 密钥；设备撤销后不再收到新 DEK 包装。

服务器只保存密文、路由字段、状态和明确白名单元数据。需要全文搜索或管理员解密时，必须另行设计显式授权部署模式，不得暗中改变默认边界。

## 后果

- Web、Flutter、Go 必须共享加密测试向量。
- 密文无法直接在服务器端搜索或渲染，管理台只能显示元数据。
- 设备撤销不能抹除历史密文，但能阻止新数据密钥分发；未来如需历史数据立即失效，需要密钥轮换。

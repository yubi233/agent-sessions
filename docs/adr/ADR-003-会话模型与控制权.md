# ADR-003：逻辑会话、运行实例与 Android 控制权

- 状态：Accepted
- 日期：2026-08-13

## 背景

一个逻辑会话可能被停止、恢复或因 Provider 限制重新启动。多个客户端还可能同时查看同一会话，必须避免旧进程或重复命令继续写入。

## 决策

拆分三个概念：

- `Session`：跨运行实例的持久身份、历史事件和加密元数据。
- `SessionInstance`：一次本地 Provider 进程运行。
- `ProviderThread`：Provider 的原生线程或会话句柄。

每次唤醒产生新的 instance id 和递增 lease epoch。Android 是唯一写控制端；所有 prompt、abort、权限、模式、Plan、Goal、Skill 命令必须携带当前 epoch。旧 instance、旧 epoch 和重复命令必须被拒绝或返回原结果。

唤醒结果统一为：

```text
resumed
restarted_with_context
unsupported
local_state_missing
workspace_moved
terminal_offline
```

`abort turn`、`stop goal`、`terminate session` 是三个不同动作，不能共用一个布尔状态。

## 后果

客户端可以在多个设备上只读查看，但只有 Android 能改变会话。Provider 无法原生恢复时仍能明确告诉用户降级结果，而不是伪装为原会话恢复。

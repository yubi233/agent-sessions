## 1. 目标与明确排除项

用已有多 Session 能力做跨 AI 工具子代理：父会话派发任务，子会话由另一（或同一）Provider 独立运行，Android 可切入子会话完整控制。补齐 Happy 移动端 nested sub-agent 看不清、不能换工具的缺口。

不实现 Provider 私有 sub-agent 协议兼容，不在 Relay 执行 Agent，不把子会话全文合并进父事件流，不自动跨未确认 Workspace/Terminal。

## 2. 进入条件、输入和依赖

- `PROTO-CRYPTO`：Delegation 命令/事件/错误进入 schema。
- `RELAY-REALTIME`：多 Session、命令幂等、lease、父子索引元数据。
- `ADAPTER-PLATFORM`：mock 可并行跑两个 Session。
- `ANDROID`：会话列表与写命令壳。
- 真实跨工具 live smoke 依赖对应 Adapter 授权；默认只跑 mock/fixture。

## 4. 数据、权限、错误和事件边界

- 任务书、约束、结果摘要端到端加密；Relay 只存 `delegation_id`、parent/child session id、provider 类型、状态、时间、密文 envelope 哈希。
- 派发与批准必须带父会话当前 Android lease epoch；子会话写操作使用子会话 epoch。
- 子会话失败、超时、Provider unsupported、Terminal 离线必须变成明确 Delegation 状态，不能伪装 completed。
- 父 Adapter 若发出“需要子代理”的私有工具调用，只能映射为 `proposed`，由 Android 确认后才创建子 Session。

## 5. 命令、smoke、targeted diagnostic、full gate 和 recording

计划命令：`task test:contract -- suite=delegation`，`task test:android` 中的派发切片。默认 `real_upstream=false`、`real_model=false`。跨 Claude/Codex 的 live 必须单独授权，并限制一次隔离 Workspace、可停止。

smoke：mock 父会话派发 mock 子会话，父收到 running→completed 摘要。  
diagnostic：跨 Provider 目标 unsupported、Workspace 越界、旧 epoch、Web 写拒绝。  
full gate：批准、取消、子会话切入、父不出现子全文。  
recording：无真实模型时用 mock headed/Flutter macOS 演示；有授权再另开 recording。

## 6. 退出条件、阻塞和残余风险

退出：父子 Session 图可查询；跨 Provider mock 派发成功；越界与只读拒绝；Android 能确认并打开子会话；父事件无子全文；无授权 live 标 `blocked`。

阻塞：schema 无法表达 Delegation、Relay 需要明文任务、或只能靠 Provider 原生 sub-agent。残余风险：真实 Provider 并行进程与额度；首版不做自动跨机派发。

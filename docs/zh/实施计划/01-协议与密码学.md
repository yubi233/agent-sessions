## 1. 目标与边界

负责跨 Go、TypeScript、Dart 的 REST、事件、命令、错误、能力和 E2EE 事实源。服务器只路由和保存密文，不负责解密、正文搜索或 Git 内容解释。

不负责 Gin handler、Provider 进程、客户端页面和生产密钥托管。

## 2. 进入条件、输入和依赖

无上游代码依赖，但必须先锁定 Go、Node/pnpm、Flutter/Dart、JDK、代码生成器和 JSON Schema/OpenAPI 版本。所有消费方只能从 `packages/protocol` 和 `packages/crypto` 生成或映射类型，不能复制 DTO。

## 4. 数据、权限、错误和事件边界

协议明确 Android owner/key-admin、Web/Admin readonly、Daemon terminal 的设备角色；Git endpoint 仅为加密 Daemon RPC。生成 DTO 不等于领域模型，所有端在 transport 边界映射。服务器不得因 schema 缺失而解密正文。

## 5. 命令、smoke、targeted diagnostic、full gate 和 recording

P0 建立后使用 `task generate`、`task test:protocol`、`task test:crypto`、`task docs:verify`。本计划无真实浏览器/Provider/模型 gate；三端互解 vectors 是 full gate。

## 6. 退出条件、阻塞和残余风险

退出：三端互解 golden vectors；错误/版本行为有 contract tests；schema 生成无漂移；服务器日志/数据库扫描无明文。阻塞：任何端无法互解、恢复码语义未定、Provider 需要未定义字段或 Relay 必须解密正文。残余风险：真实 Provider 和设备存储由后续计划验证。

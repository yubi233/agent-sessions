# 分项目实施计划模板

每个项目计划应保留以下章节，避免只有愿望清单而没有可执行交接物。

```markdown
# <计划名称>

## 计划元数据

| 字段 | 内容 |
| --- | --- |
| plan_id | 唯一计划 ID |
| owner | 责任项目/角色 |
| status | planned/in_progress/blocked/complete |
| target | 目标里程碑 |
| protocol_revision | 消费的 schema/crypto 版本 |
| adr | 关联 ADR |

## 1. 目标与明确排除项

## 2. 进入条件、输入和依赖

## 3. 工作包

| 工作包 | 前置输出 | 实现步骤 | 交接输出 | 测试 ID | 最低层级 | 证据 | 回滚/开关 |
| --- | --- | --- | --- | --- | --- | --- | --- |

## 4. 数据、权限、错误和事件边界

## 5. 命令、smoke、targeted diagnostic、full gate 和 recording

## 6. 退出条件、阻塞和残余风险

## 7. 文档回填清单
```

约束：schema、错误码、能力枚举、crypto vectors 和测试 ID 只有一个 owner；fixture、报告和录屏不保存 token、正文、diff 或解密附件。计划文档完成不等于对应代码或 gate 完成。

## 1. 目标与非目标

### 目标

1. 统一视觉语言：圆角、间距、字号角色、空状态、错误横幅等收敛到 `app_theme.dart` 的 token 体系。
2. 修复纯视觉缺陷：文本溢出风险、缩进错位、对比度不达标（WCAG AA）。
3. 补齐主题 token 缺口（spacing/radius/size 常量、`titleSmall`/`labelSmall` 角色），让后续屏幕不再各自为政。

### 非目标（明确不做）

- 不改任何交互：回调、手势、Focus/onKeyEvent、提交时机、滚动语义、路由。
- 不改 widget Key 名称/位置、Semantics label/flag —— 它们是测试锚点。
- 不改用户可见文案（如 `"No messages yet"`）：文案受 widget 测试断言，视为 test-visible，如需修改单独评审。
- 不合并"双胞胎"组件本身（仅对齐其样式），避免移动 Key 与回调位置。
- 不碰另一工作线正在修改的文件：`apps/mobile/lib/main.dart`、`apps/mobile/lib/app/local_runtime_environment_*.dart` 及 daemon/relay 相关改动。

3. **近空屏观感**：最近会话（内容止于 y147）、设置中心（y471 以下全黑）、消息深链（y246）在 fixture 下大面积留白，暴露空状态视觉不统一（代码审计 §4 有五套空状态写法）；fixture 数据稀疏（单会话两条事件、冻结时钟、终端列表多数场景为空）放大了留白。
4. **布局骨架健康**：左右边距稳定 18px（480 宽下），会话壳底部输入坞约 232px，无硬溢出；问题集中在组件级细节而非骨架。

## 3. 对比度核算（基于 app_theme.dart 实际色值）

| 配对 | 对比度 | 判定 |
|---|---|---|
| 深色次级文本 #a1a1a6 / 画布 #000 | 8.16:1 | ✅ |
| 深色次级文本 / 卡面 #1d1d1f | 6.54:1 | ✅ |
| 浅色次级文本 #6e6e73 / #f5f5f7 | 4.66:1 | ✅（12px 小字偏紧） |
| 强调色 ocean 深 #0a84ff / #000 | 5.76:1 | ✅ |
| **按钮文字 白 / ocean 深 #0a84ff** | **3.65:1** | ⚠️ 大号加粗达标（3:1），普通文本标准（4.5:1)不足 |
| **边框 #424245 / 卡面 #1d1d1f（非文本对比）** | **1.68:1** | ❌ 低于 WCAG 1.4.11 的 3:1 |

结论：调色板本体健康，真实失败来自**继承错误**而非色值设计——最典型的是 git diff 正文显式指定了字体却没指定颜色，继承了 bodyMedium 的灰色次级文本（详见 B1-1）。

### 中优先（一致性债务）

- **缺两个文本角色**：`AppTheme.textTheme` 未定义 `titleSmall`/`labelSmall`，而 daemon_observation/settings/usage/command_palette/code_viewer 等 10+ 处在使用 → 静默回落 Material 默认 11px/letterSpacing0.5。在 AppTheme 补定义即可一次修正全部调用点（F-TS）。
- **四套页面标题体系**：headlineSmall（terminal/daemon）、裸 bodyMedium 句子（recent）、ad-hoc 16px w600（settings 三处 ：289/:296/:384）、卡内 titleMedium（session_info/usage）。统一映射到 titleLarge/titleMedium。
- **错误横幅多套**：_StatusScaffold 无图标 all(12)、_InlineError 图标 all(10)、workspace 拒绝横幅无边框 h10/v6 且 retry 是 OutlinedButton 而他处均为 IconButton（workspace_files:438 vs settings:187 等）——重试控件形态保持原 widget 只对齐观感（换控件=红线）。
- **卡片 padding 梯度混乱**：同类描边卡 16/14/12/10/(12,10,8,8) 并存（screens.dart:466,662; session_screens.dart:4187,4446,1246,1764,2097 等）。
- **圆角离群**：系统 8 之外散落 22（composer pill）、6（provider chip/workspace ripple/git 行）、4（breadcrumb ripple）。
- **fontSize 11 字面量**：fork/duplicate/archive 菜单副标题（session_screens.dart:1047,1063,1076），同级项已用 labelSmall。
- **chip 第三态失控**：capability unsupported 未着色走 M3 默认底（settings_screens.dart:524-544），与前两态视觉无关。
- **语义色漂移**："出错会话"用 warning 琥珀（recent_sessions:210-214）而 git 错误用 error 红；daemon failed/rejected 同样落 warning。视觉映射梳理（不改判断逻辑）。
- **边框取径分裂**：部分卡用 dividerColor 部分用 appColors.border（当前同值，未来必分叉）（git_diff:425,550,606,812; workspace_files:343,369）。
- **列表密度不一**：settings index h12/minVP12、recent 非 dense h8、palette/files dense 默认16……padding 可统一；`dense` 开关影响 48dp 触达属红线不动。
- **tab 标签无文本角色**（session_header.dart:149-154），继承环境字号；42px 定高在大字号下有裁剪风险。
- **空状态五种写法**：icon+title+caption（recent/terminal，最佳实践）、icon+caption 无标题（daemon/deep_link）、裸 caption（settings/palette/files/git）、裸文本（pairing/devices）、整屏 SizedBox.shrink()（code_viewer content==null 时完全空白，code_viewer_screens.dart:131；usage chart providers 空时静默消失 usage:223-225）。

### 低优先（token 清扫）

阴影唯一一处硬编码 Color(0x12000000)（session_screens.dart:2912）；alpha 魔数 ~10 处；off-grid 间距 3/5/7/9px 多处；图标尺寸 13–20 连续散布；冗余 OutlineInputBorder 重声明 5 处；QR104/标签列72/下拉190 等安全但非流动的定值 token 化。

## 5. 实施批次（每批一个 commit，可独立 revert）

## 1. 目标与明确排除项

**核心目标**：解决 v0.2 复测对照（记录 07「v0.2 后仍存在的差距」）中已列入处理范围的六项会话能力差距，全部按既有 capability fail-closed 惯例落地并沉淀关键回归。

| 差距（来自记录 07） | Happy 基线行为 | v0.3 处理 |
| --- | --- | --- |
| permission mode 选择器 | `getAvailablePermissionModes` + `sessionSetAgentModes({permissionMode})` | P0：新增 `permission_mode` capability 与 `session.permission_mode` 命令，composer 内选择器 |
| goal 文本编辑 | `AgentGoalBar` 编辑目标（Modal.prompt + `sessionGoalAction`） | P0：`goal.edit` 命令 + 编辑 UI（复用 goal capability 门控） |
| usage 深度 | input/output/cacheCreation/cacheRead/contextSize/contextWindow + 上下文警告 | P1：usage 摘要扩展 cache 计数与 context 窗口，超阈值警告条 |
| CLI/Provider 版本过旧警告 | `MINIMUM_CLI_VERSION` + acknowledgedCliVersions 条 | P1：移动端状态条展示 Provider 版本与连接态（fail-closed 原因），不实现版本比较 |
| duplicate / 复制元数据 | quick actions：duplicate sheet、copySessionMetadata | P2：菜单 duplicate 入口（按 capability fail-closed）+ details 底表复制元数据 |
| Provider 连接态 | realtimeStatus + ConnectButton | P1：状态条连接态（随版本提示一起） |

**明确排除**：

- fork/archive 的真实数据模型与迁移（仍按 capability fail-closed，不立项）
- 实时语音、Inbox/Friends、社交 feed、付费
- Android AVD / 真机 / UnifiedPush 原生验收（延后，不阻塞 MacBook gate）
- 用 fixture 或 UI 假能力冒充真实 Provider 能力升级

## 2. 契约与数据边界

- 新增 capability `permission_mode`：加入 `internal/adapter/spi.go` 的 `CapabilityNames`；所有真实 Adapter（opencode/claude/codex/openclaw）默认 `unsupported`（fail-closed），mock 与 Flutter fixture 声明 `native`；未知状态一律 unsupported。
- 新命令 kind：`session.permission_mode`（payload：`permission_mode`）、`goal.edit`（payload：`objective`）；两者都走 Android owner + 正数 lease_epoch + 幂等键链路。
- `SessionControlState` 扩展：`permissionMode`、`availablePermissionModes`、goal 增加 `objectiveEditable` 语义（编辑后更新）；usage 扩展 `cacheReadTokens`、`cacheCreationTokens`、`contextWindowTokens`。
- 版本/连接提示只消费 capability matrix 白名单：`version`、`available`、`reason`；不新增 Relay 端点，不展示会话正文。
- 复制元数据只复制白名单字段（会话 ID/Provider/工作区），不复制密文、正文或 token。

## 5. 退出条件、阻塞与残余风险

**退出**：六项差距均有 Dart/widget 回归与可见证据；新 capability 与命令 fail-closed 契约通过；全量 Flutter/Go/headed Web 回归通过；录屏前完成回归登记并产出 5fps 证据。

**阻塞**：无（全部为本地 fixture 可验证的移动端工作包）。

**残余风险**：真实 Provider 的 permission mode / goal 编辑依赖各自 Adapter 后续实现；版本比较（MINIMUM_CLI_VERSION）不实现；Android 真机与系统 Push 继续延后。

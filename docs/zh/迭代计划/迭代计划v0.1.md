## 1. 目标与明确排除项

**核心目标**：交付 Android 唯一写控制端，会话能力完整对齐 Happy 移动端，包括：

- 配对 / owner bootstrap / 撤销 / 恢复码
- 会话列表、start / stream / abort、流式 Markdown
- 权限 / 问题 / Plan / Goal / Skill 风险确认、参数输入、调用结果
- 跨工具子代理（Delegation 父子 Session 图 + Android 确认卡 + 子会话切入）
- 图片 / 文本附件（大小 / MIME / 压缩限制、上传重试）
- Git DiffView（统计 / 文件树 / unified-split / hunk / 折叠 / 语法高亮 / rename / binary / submodule / LFS / 分页 / 超大 diff 保护）
- 生命周期 / 后台恢复 / 通知（UnifiedPush + app 内降级）
- 真实 Provider 能力集成（Claude / Codex / OpenCode / OpenClaw live smoke）

**明确排除**：

- Git 写操作、远程 shell、语音、社交、付费、Happy wire protocol 兼容
- Relay 做 Provider 调度或执行子代理
- 服务器端正文搜索、管理员临时解密

## 4. 数据、权限、错误和事件边界

- Drift 永远只存密文 envelope、cursor 和最小索引；明文解密态只在内存，日志/截图/报告禁含正文。
- Android 发送写意图，Relay 依据认证 device、lease epoch、scope 和 capability 决定接受；客户端不能自行提升权限。
- `native/emulated/unsupported` 决定按钮可用性和说明；不支持时不伪造 Provider 写操作。
- Diff 来自 Daemon 加密 RPC，snapshot stale 必须给用户可重试状态，而非混合渲染。
- Delegation：父子 Session 图、加密任务书、子会话独立 Provider，Android 确认卡，父事件只收摘要不复制全文。

## 5. 命令、smoke、targeted diagnostic、full gate 和 recording

P0 后使用 `task test:android`、`task test:flutter:local`；本轮以 MacBook 上可见 Flutter macOS 桌面窗口作为用户可见 gate。Flutter gate 先构建固定 debug App、运行长期 unit/widget 回归，再直接启动该 App 并用 CoreGraphics 以严格 5fps（每 `200ms` 一帧）采集已登记 fixture 场景：先取 `100` 候选帧，再筛选连续 `25` 帧最终 PNG，避免把一秒或总共 5 张截图误称为 5fps。`task test:flutter:record -- --gate-report <passed-report>`仅在满足同一窗口证据契约的 full gate 后录制`VISUAL-MOBILE-11/12/14`的 5fps MP4，并校验帧数、帧率与尺寸。Android AVD、Android 原生存储、UnifiedPush 与真机/后台行为均不阻塞通过，后续阶段需显式标记设备型号、Android 版本和授权。浏览器验收仍使用 `task test:e2e` 的 headed Chrome。录屏不包含真实会话内容。经用户授权后，`task test:real -- --provider opencode --model opencode-go/deepseek-v4-flash --retries 3`用于独立的 OpenCode CLI live smoke：它证明真实模型请求，不替代 Flutter/macOS、Android 或 Adapter transport gate。

## 6. 退出条件、阻塞和残余风险

本地退出：MacBook 本地 Flutter macOS gate 通过，验证 Android 写控制端的共享业务链路；后台/断线/网络切换不会丢事件或重复命令；权限、问题、Plan、Goal、Skill 按能力工作；Git/附件边界通过；跨工具子代理图+确认卡可用；对应 5fps fixture 录屏已归档。Android AVD、Android Keystore/Drift 原生集成、UnifiedPush 与真机结果是后续硬化阶段的独立退出条件，不阻塞本轮。

阻塞：OpenCode Go 的`opencode-go/deepseek-v4-flash`已通过授权 CLI live smoke，但`internal/adapter/opencode`仍没有 Start/Resume/事件流 transport，移动端真实控制保持`blocked`；不得由 UI、fixture、HTTP 200、CLI smoke 或录屏替代。Claude、Codex、OpenClaw 的真实 live smoke 仍无专属凭据/授权，保持`blocked`。Android SDK/模拟器、Keystore/UnifiedPush 无法验证只记录为后续原生硬化风险。

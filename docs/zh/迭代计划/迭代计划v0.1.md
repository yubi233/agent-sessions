## 1. 目标与明确排除项

**核心目标**：交付 Android 唯一写控制端，会话能力完整对齐 Happy 移动端，包括：

- 配对 / owner bootstrap / 撤销 / 恢复码
- 会话列表、start / stream / abort、流式 Markdown
- 权限 / 问题 / Plan / Goal / Skill 风险确认、参数输入、调用结果
- 跨工具子代理（Delegation 父子 Session 图 + Android 确认卡 + 子会话切入）
- 图片 / 文本附件（大小 / MIME / 压缩限制、上传重试）
- Git DiffView（统计 / 文件树 / unified-split / hunk / 折叠 / 语法高亮 / rename / binary / submodule / LFS / 分页 / 超大 diff 保护）
- 生命周期 / 后台恢复 / 通知（UnifiedPush + app 内降级）
- 真实 Provider 能力集成（Claude / Codex / OpenCode / OpenClaw live smoke）

**明确排除**：

- Git 写操作、远程 shell、语音、社交、付费、Happy wire protocol 兼容
- Relay 做 Provider 调度或执行子代理
- 服务器端正文搜索、管理员临时解密

## 2. 进入条件、输入和依赖

- 输入：稳定 Dart DTO / crypto vectors、Relay auth / realtime mock、Daemon Git fixture、Adapter capability fixtures、Happy 移动端能力清单（配对、会话流、Plan/Goal/Skill、附件、DiffView、通知、跨工具子代理）。
- 依赖：Material 3 + Riverpod + go_router + Dio + web_socket_channel + Freezed + Drift + Keystore + cryptography + flutter_local_notifications + UnifiedPush Kotlin 插件。
- 用户选择：首个 Android 为 owner / key-admin；会话写命令始终附当前 controller / lease 语义。

## 4. 数据、权限、错误和事件边界

- Drift 永远只存密文 envelope、cursor 和最小索引；明文解密态只在内存，日志/截图/报告禁含正文。
- Android 发送写意图，Relay 依据认证 device、lease epoch、scope 和 capability 决定接受；客户端不能自行提升权限。
- `native/emulated/unsupported` 决定按钮可用性和说明；不支持时不伪造 Provider 写操作。
- Diff 来自 Daemon 加密 RPC，snapshot stale 必须给用户可重试状态，而非混合渲染。
- Delegation：父子 Session 图、加密任务书、子会话独立 Provider，Android 确认卡，父事件只收摘要不复制全文。

## 5. 命令、smoke、targeted diagnostic、full gate 和 recording

P0 后使用 `task test:android`、`task test:android:e2e`；模拟器用于主 gate，真机/UnifiedPush/后台行为需显式标记设备型号、Android 版本和授权。录屏必须在 integration gate 后，且不包含真实会话内容。

## 6. 退出条件、阻塞和残余风险

退出：Android 是唯一可写入口；后台/断线/网络切换不会丢事件或重复命令；权限、问题、Plan、Goal、Skill 按能力工作；Git/附件边界通过；真机结果有明确验证口径；跨工具子代理图+确认卡可用；真实 Provider live smoke 经授权后通过。

阻塞：缺 Android SDK/模拟器、Keystore/UnifiedPush 无法验证或协议未冻结。残余风险：真实 Provider 能力必须引用专属 adapter evidence，不可由 UI 测试替代。

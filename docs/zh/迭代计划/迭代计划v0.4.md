## 1. 目标与明确排除项

**核心目标**：复刻 Happy 全项目对照中列为 P0/P1/P2 的核心功能，并用 Apple 官网设计语言（大留白、SF 排版层级、毛玻璃、精炼动效、浅/深色跟随系统）重做全部界面。

**功能复刻范围（来自记录 07 欠缺清单）**：

| 优先级 | 复刻对象 | Happy 参考 | 交付 |
| --- | --- | --- | --- |
| P0 | 设置页体系 | `settings/`（account、appearance、language、usage、connect） | 设置中心 + 主题系统（浅/深/跟随 + accent）+ 账户/用量/连接项 |
| P0 | 机器/终端状态页 | `machine/[id]`（status/logs/restart/update）、`terminal/connect` | 机器详情页（版本/状态/最近活动/重启入口） |

| P1 | 会话 info 页 | `session/[id]/info`（machine/copy/kill/share/revert/summarize） | info 页：机器/复制/终止/分享入口 |
| P1 | 用量统计页 | `UsagePanel`（today/7days/30days 图表） | 用量图表页（脱敏计数） |

**UI 优化范围（Apple 风格，全端）**：

- 设计令牌：Apple 语义色板（accent/背景/分隔/警示）、8 点间距网格、圆角 12/16/24、SF 排版层级（LargeTitle/Title/Headline/Body/Footnote/Caption）、250-300ms 缓动曲线。
- 主题系统：浅色/深色/跟随系统（`ThemeMode.system`）+ 可切换 accent；替代当前硬编码 `ThemeMode.dark`。
- 组件打磨：AppBar/底栏/控制条毛玻璃（BackdropFilter）、列表卡片化、空状态插图感、Hero/淡入过渡、键盘避让与滚动平滑。
- Web/Admin 同步：`styles.css` 迁移为设计令牌 + 亮/暗主题跟随系统；能力矩阵/只读页对齐卡片与排版。

**明确排除**：

- 实时语音、Inbox/Friends/社交、付费、GitHub 集成、远程 shell、Git 写、Happy wire 兼容
- Android AVD / 真机 / UnifiedPush 原生验收（延后）
- 真实会话分享公链与真实 changelog 服务器（fixture 链路先行）
- 用 fixture/UI 冒充真实 Provider 能力升级

## 2. 契约与数据边界

- 主题系统新增客户端本地设置（`ThemePreference {system, light, dark}` + accent），只存内存/本地偏好，不进 Relay。
- 机器状态页数据来自 daemon `status`/`doctor` 输出白名单（版本、状态、最近活动时间），不暴露日志原文或敏感路径。
- 代码查看器复用 `WorkspaceFilesRepository` 只读边界：文本文件经路径校验后渲染；二进制/超大仍走受限摘要；无 shell、无写入口。
- 用量统计页只消费脱敏计数（input/output/cache/context），不展示正文；fixture 提供 today/7days/30days 序列。
- 命令面板：写命令按既有 capability/lease 门控，未授权命令 fail-closed。
- 分享/Artifacts 为 fixture 链路：不创建真实外部链接或产物存储契约。
- UI 重构必须保留既有稳定测试 Key/`data-testid`（选择器契约），新增组件用新 Key 登记。

## 5. 退出条件、阻塞与残余风险

**退出**：P0-P2 功能复刻均有 fixture 回归与可见证据；主题系统（浅/深/跟随 + accent）与 Apple 令牌全端生效；既有稳定测试 ID 全部保持通过；新视觉场景 full gate + 5fps 录屏完成；Web/Admin 令牌化回归通过。

**阻塞**：无（全部本地 fixture 可验证）。

**残余风险**：UI 重构期间旧视觉截图会变化，需重跑全量视觉门禁；分享/Artifacts/changelog 为 fixture 链路，真实服务待后续；Android 真机与系统 Push 继续延后；i18n 只做骨架（中文为主，不做多语言文案）。

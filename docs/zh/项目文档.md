# Agent Sessions 项目文档

> 文档状态：实现基线（2026-08-14）
>
> 存储决策已从 PostgreSQL + Redis 调整为单租户 SQLite：Relay 与 Daemon 共用 `modernc.org/sqlite`。presence / 限流为进程内可重建状态，不再依赖 Redis。

> 本文是项目的权威事实源。代码、测试、部署文件和其他计划文档应引用本文；发生实现变化时先更新本文，再更新测试与实施记录。

## 1. 当前状态

仓库按 P0–P5 分阶段落地。权威存储是 SQLite 文件，不是 PostgreSQL。以下内容描述当前目标架构与已确认实现边界。

截至 2026-08-14：P0（工程、协议、密码学、本地运行基线）已完成并通过 gate；Go 与 TypeScript 已跨语言互解同一组 crypto vectors，headed 浏览器与录屏脚本已建立。P1（Relay 身份/持久化 + 实时同步）已交付：账号注册/登录/刷新/注销、owner bootstrap、设备配对/审批/撤销/恢复码、Session/Command/ControlLease(fencing)/outbox、进程内 presence、账号级 SSE 与 /v1 REST 路由均落地并有 Go 集成回归与 headed Web 只读回归证据。P2（Daemon 核心、Workspace 安全、Git 只读 RPC、Adapter 平台与 mock runtime）已交付：Adapter SPI/能力三态/六种唤醒、路径不可逃逸校验、porcelain v2 只读 diff、Daemon 本地 SQLite 状态与离线 outbox 幂等重放，均有单元/集成回归。P3（四类 Provider Adapter）已交付 SPI 与能力矩阵契约（`/v1/capabilities`），真实 CLI/Gateway live smoke 因缺少凭据标记 `blocked`。P4（客户端）已交付：Web 只读客户端（设备/会话/能力只读）、Admin 运维只读控制台（脱敏元数据、无写入口）与 Android mock 控制壳，均有组件测试与 headed 浏览器/Flutter widget 回归。P5（安全、性能、灾备与发布）为下一阶段。

## 2. 产品定位

Agent Sessions 是一个类 Happy 的远程编码会话平台：

- PC 上的本地服务负责访问工作区、启动本地 Agent、转发事件和执行安全的 Git 读取操作。
- 服务器上的 Relay 负责身份、配对、密文路由、事件持久化、在线状态和命令转发。
- Android 是默认的唯一写控制端，负责完整移动会话控制。
- Web App 提供只读会话查看和 Git diff；管理平台提供只读运维与设备元数据查看，owner Android 管理设备密钥生命周期。

本项目借鉴 Happy 的产品能力和开源实现经验，但不兼容 Happy 的 wire protocol、Socket.IO 事件或客户端。

## 3. 已确认的产品决策

| 领域 | 决策 |
| --- | --- |
| 部署 | 单租户自托管；Docker Compose 单机部署 |
| 设备关系 | 一个账号绑定多个 PC 和客户端；首个 Android 设备为 owner |
| PC 平台 | macOS、Windows、Linux |
| 运行时 | Claude、Codex、OpenCode、OpenClaw 四类并行接入 |
| 运行时接入 | 各类型优先原生深度集成，PTY 只作为显式兼容降级 |
| 唤醒 | 启动/恢复 Agent 会话，不负责唤醒或远程开机 PC |
| 控制权 | Android 固定为唯一写控制端；Web/管理台只读 |
| Git | 在线只读 status、文件列表和 diff；不做 stage、discard、commit |
| 加密 | 消息、文件、diff 和工具参数端到端加密；服务器只看白名单元数据 |
| 通道 | REST + SSE + WebSocket |
| 存储 | SQLite 是事件、命令、ControlLease/fencing epoch 的权威；进程内内存只处理可重建的 presence、短租约提示、限流和广播 |
| 推送 | UnifiedPush 优先；无 distributor 时降级为应用内实时通知 |
| 会话留存 | 密文长期保留，用户可以手动删除 |
| 附件 | 受大小和 MIME 限制的图片与文本文件 |
| API | 仅官方客户端使用的内部版本化 API |
| 更新 | macOS pkg、Windows MSI、Linux deb/rpm/tar，签名后手动升级 |
| 技术选型 | Go + Gin、Vue3 + TypeScript、Flutter + Dart；具体依赖见[技术选型](技术选型.md) |

重要语言边界：Vue3 Web/Admin 使用 TypeScript；Flutter Android 使用 Dart。Flutter SDK 不支持用 TypeScript 编写 Flutter UI 或业务代码。如果 TypeScript 必须覆盖 Android 客户端，需在实施前将 Flutter 替换为 React Native，该变更会影响导航、状态、加密、DiffView、通知和测试方案。

## 4. 系统拓扑

```text
                         +----------------------+
                         | Android Controller   |
                         | 唯一写控制端         |
                         +----------+-----------+
                                    |
                         REST / SSE / WebSocket
                                    |
+----------------+        +--------v---------+        +----------------+
| Vue Admin      |-------> | Relay Server     | <------| Vue Web App    |
| 运维、只读     |         | Go               |        | 会话、只读     |
+----------------+         +---+----------+---+        +----------------+
                                |          |
                          WebSocket      SQLite
                                 |          |
                          +------v----+  in-memory presence
                          | PC Daemon  |
                         | Go         |
                         +--+--+--+--+
                            |  |  |
                     Claude/Codex/OpenCode/OpenClaw
```

Relay 不访问 PC 工作区，也不执行 Agent 命令。所有工作区相关能力必须经由已认证的 Daemon 完成。

## 5. 组件职责

### Relay Server

- 账号登录、设备配对、owner 批准和撤销。
- Terminal、Project、Workspace、Session 的元数据索引。
- 密文事件、命令状态和用户游标的持久化。
- WebSocket 终端连接、Android 订阅和 RPC 路由。
- SSE 增量事件读取，支持 `Last-Event-ID` 恢复。
- 控制权租约、幂等键、fencing epoch、限流和 outbox。
- 健康检查、指标、脱敏日志和备份接口。

### PC Daemon

- 系统服务、CLI、进程监督和本地 SQLite 状态。
- 扫描常用目录，用户确认后登记 Git 项目根目录。
- 维护 Terminal 长连接和断线重连。
- 启动、恢复、停止本地 Session Instance。
- 适配四类 Agent，统一为 canonical event stream。
- 在 Workspace 安全边界内执行 Git 只读 RPC。
- 使用系统 Keychain 保存本地密钥和设备凭据。

### Android App

- 登录、二维码配对、设备撤销和恢复码恢复。
- 项目、Workspace、Session 列表与会话详情。
- 新建、唤醒、恢复、停止、终止和删除会话。
- 流式消息、工具调用、权限、问题、plan、goal、skill、跨工具子代理派发和附件。
- 离线缓存、事件游标、断线恢复和通知。
- 项目级 Git diff 只读查看。

### Vue Web App

- 查看项目、Workspace、Session、消息、工具事件和父子 Delegation 图。
- 查看在线状态、错误、计划、目标和 Git diff。
- 不发送 prompt、审批、skill、plan、goal 或派发控制命令。

### Vue Admin

- 设备、Terminal、版本、在线状态和连接错误。
- 健康检查、流量和脱敏审计元数据；配对/撤销状态只读展示。
- owner Android 是设备 key-admin，负责批准、撤销与恢复码；Admin 没有这些操作权限，未来扩权必须单独新增 ADR、角色和 API。
- 不显示消息正文、文件内容、diff、工具参数或附件内容。

## 6. 领域模型

```text
Device
  └── Terminal
        └── Project
              └── Workspace
                    └── Session (逻辑持久会话)
                          ├── SessionInstance (一次运行/唤醒)
                          │     └── ProviderThread (原生线程句柄)
                          └── Delegation (产品层子代理任务)
                                └── Child Session (独立会话，可换 Provider)
```

核心实体：

- `Device`：设备身份、公钥、角色、撤销状态和最后在线时间。
- `Terminal`：PC 主机、平台、版本、能力和心跳状态。
- `Project`：仓库指纹、远程身份和加密显示名。
- `Workspace`：Terminal、Project、canonical root、分支或 worktree。
- `Session`：跨运行实例保留的逻辑会话、事件序号和加密元数据。
- `SessionInstance`：一次 Agent 进程运行，拥有 instance id 和 lease epoch。
- `SessionEvent`：有序、可重放的端到端加密事件。
- `Command`：异步控制请求及状态，使用 idempotency key。
- `ControlLease`：当前写控制端和 fencing epoch。
- `Plan`、`Goal`、`SkillDescriptor`：同一会话内的产品层资源，不是跨工具子代理。
- `Delegation`：父 Session 派发的子代理任务；子代理是独立 Child Session，可使用不同 Provider。详见 ADR-007。
- `AttachmentBlob`：分块上传的端到端加密附件。

唤醒结果必须明确区分：

```text
resumed
restarted_with_context
unsupported
local_state_missing
workspace_moved
terminal_offline
```

## 7. 传输契约

### REST

用于认证、配对、快照、历史分页、附件和异步命令提交。所有写操作支持请求幂等键；会话写命令仅接受当前 Android controller。以下为计划中的最小 inventory，最终 OpenAPI 是唯一 wire contract。

计划中的最小路由：

```text
POST   /v1/auth/login
POST   /v1/auth/refresh
POST   /v1/auth/logout
GET    /healthz
GET    /readyz
POST   /v1/pairing/requests
GET    /v1/pairing/requests/{id}
POST   /v1/pairing/requests/{id}/approve
POST   /v1/pairing/requests/{id}/cancel
POST   /v1/recovery-codes/restore
GET    /v1/devices
DELETE /v1/devices/{id}
GET    /v1/terminals
GET    /v1/projects
GET    /v1/workspaces
GET    /v1/sessions?cursor=
GET    /v1/sessions/{id}/snapshot?after_seq=
GET    /v1/sessions/{id}/delegations
POST   /v1/terminals/{id}/commands
POST   /v1/sessions/{id}/commands
GET    /v1/commands/{id}
POST   /v1/workspaces/{id}/git/status
POST   /v1/workspaces/{id}/git/changes
POST   /v1/workspaces/{id}/git/diff
POST   /v1/attachments/chunks
POST   /v1/attachments/{id}/complete
GET    /v1/capabilities
GET    /v1/version
GET    /v1/events
```

### SSE

SSE 是账号级的可恢复读取通道。客户端通过 `Last-Event-ID` 或 `after_seq` 请求缺失事件；presence 不写入 SSE 历史。

### WebSocket

WebSocket 分为 authenticated controller 连接和 terminal 连接。首帧完成 challenge/hello、协议版本、设备身份、能力和游标协商。命令和事件均包含：

```json
{
  "protocol_version": 1,
  "message_type": "command|event|presence|ack",
  "message_id": "...",
  "trace_id": "...",
  "scope": {"terminal_id": "...", "workspace_id": "...", "session_id": "..."},
  "issued_by_device": "...",
  "lease_epoch": 0,
  "idempotency_key": "...",
  "payload_version": 1,
  "payload": {}
}
```

服务器从认证连接上下文推导作用域，不信任客户端自行填写的目标前缀。SQLite 事务校验当前 `ControlLease`、epoch、target instance、deadline 和幂等键；内存 lease hint 只能加速提示，不能决定接受命令。

## 8. 统一能力模型

每个 Adapter 在运行时上报能力状态：

```text
native      原生支持并通过契约测试
emulated    由 Daemon 或产品层模拟，语义有限
unsupported 明确不支持，客户端禁用入口并说明原因
```

能力至少包括：

```text
start, resume, abort, permission, question, plan, goal,
skill_catalog, invoke_skill, model_select, effort_select,
attachments, file_read, git_read, usage,
delegate_session, delegate_cross_provider
```

客户端不得根据 Agent 类型硬编码能力，必须消费 capability payload。

## 9. 安全边界

- 邮箱/密码只验证账号，不派生正文解密密钥。
- 每设备使用 Ed25519 身份签名和 X25519 密钥交换。
- 项目或会话生成独立 DEK，并包装给已授权设备。
- AES-256-GCM + HKDF；AAD 绑定实体、事件类型、版本和序号。
- Android 使用 Keystore，PC 使用系统 Keychain，Web 使用最小化浏览器存储。
- 服务器保存密文和明确白名单元数据，不提供正文搜索。
- 项目扫描只登记用户确认的目录；Git 命令必须参数化执行。
- 所有会话写操作要求 Android 控制端身份和当前 lease epoch。
- 旧 instance、旧 epoch 和重复 idempotency key 必须被拒绝或返回原结果。

## 10. Git 读取边界

Git 服务由 Daemon 提供，即使 Session 休眠也可读取 Workspace。Relay 的 Git 路由只是端到端加密 RPC 代理：Daemon 执行 Git、路径检查和 `snapshot_token`，Relay 不解析或缓存 diff。必须支持：

- porcelain v2 或等价结构化 status 解析。
- 文件列表、staged/unstaged、rename、binary、submodule、LFS、untracked。
- 文件级和全量 diff，分页、压缩、最大字节数和大文件提示。
- `snapshot_token`，避免分页期间混用不同工作区状态。
- canonical root、realpath、符号链接和 repo-relative path 校验。

首版明确不提供 stage、unstage、discard、commit、push 或任意 shell。

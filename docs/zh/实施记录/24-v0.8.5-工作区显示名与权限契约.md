## 1. 本次接管范围

### ③ 会话副标题/空状态工作区名显示错误

用户实测：会话页副标题恒显示写死字符串 'agent-sessions'（与当前所选工作区无关）；空状态 hero 第二行显示伪造本地路径 '~/code/agentProject/agent-sessions'。根因（计划 §1.3）：全仓库只有 fixture 赋值过 `project_name`，Relay `sessionView` 从不下发 `workspace_name`；真实链路恒 null → 恒落硬编码兜底。

### ② 权限 mode 命令契约（wire 层）

移动端 kind `session.permission_mode` + payload key `permission_mode` 与 Daemon 权威契约 `mode.set` + `mode_id` 不一致（计划 §1.2 第二处契约错位），移动端提交会被 Daemon 拒为 unsupported。

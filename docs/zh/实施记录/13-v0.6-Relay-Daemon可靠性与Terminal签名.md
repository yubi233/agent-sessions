### P1 验证记录

- 根因层（`internal/domain/signed_terminal_test.go`）：正确签名通过、challenge 重放拒绝、未签发挑战的 hello 拒绝、错误签名拒绝、过期时间戳拒绝且不消费挑战、required 模式 bearer 返回升级哨兵错误、公钥登记幂等/retired 复用拒绝/双读一写收口、跨账号与撤销设备 fail-closed、挑战跨 Relay 重启一次性保持。
- 存储层（`internal/store/terminal_auth_nonce_test.go`）：nonce 重启后查重保留；新增清理阈值回归（时钟前进不得清除重放窗口内的历史 nonce）。
- 纵向层（`internal/relay/v06_signed_terminal_contract_test.go`，已纳入 `task test:e2e:relay`）：真实 HTTP 栈上完成 challenge → signed hello → signed heartbeat → 命令投递 → signed ack/result/event 全闭环；覆盖挑战重放 NONCE_REUSED、篡改 body hash SIGNATURE_INVALID、换 nonce 幂等重试、重复 event_id 幂等 receipt、owner 登记密钥双读、Terminal 自登记 403、撤销登记密钥即时 fail-closed、设备撤销后 challenge 即不可获取、required 模式全部 Terminal 端点（含 usage）返回 426 UPGRADE_REQUIRED 且 signed hello 只声明 `auth_modes=["signature_v1"]`。
- P1 发现并修复两个协议缺陷（均有回归沉淀）：
  1. **body hash 循环依赖**：原实现对包含 signature 字段的完整 body 计算哈希，签名将覆盖自身。已冻结规则并双端实现为"删除顶层 signature 成员后的紧凑 JSON 原文"（`internal/httpapi.terminalSignedBody` + ADR-012/OpenAPI 描述回填）。
  2. **nonce 清理阈值缺陷**：原实现以新记录的过期时间（now+5min）作为过期清理阈值，时钟前进会提前删除仍在重放窗口内的 nonce 导致重放放行。已改为以当前时间为清理阈值（`ConsumeTerminalAuthNonce` 增加 now 参数 + store 回归）。
- 口径：`local_test=true`、`fixture_data=true`、`real_browser=false`、`real_model=false`、`real_upstream=false`、`headless=false`；生产 Daemon 进程的私钥供给与 restart.sh 接线属于 P4 回滚演练范围。

## 2. P0：持久化根与历史迁移

### 已完成

- `Start`/`Resume` 使用 canonical 工作区根下的 `<workspaceRoot>/.dsh-sessions`；`Detect` 才使用可清理的临时根。
- `DSH_SNAPSHOT_SESSIONS_ROOT` 注入精确 backend 根，不再自动追加 `sessions` 子目录；`DSH_SESSION_CWD` 为无会话沙箱回退根。
- `AGENT_SESSIONS_DSH_PERSIST_COMPRESSION` 显式选择 `none` 或 `zstd`；桥环境通过 `DSH_SNAPSHOT_COMPRESSION` 固定同一后缀，迁移会把旧 artifact 转码到目标格式。未设置时生产默认使用明文 JSONL，未知值 fail-closed。
- 生产 `Start`/`Resume` 会把工作区规约为 realpath，并用同一 canonical cwd 生成持久化根、`session/new`/`session/load`/`session/resume` 参数；迁移目标 header 也规范化为该 cwd，避免 macOS `/var` 与 `/private/var` 别名造成恢复误报。
- 持久化目录增加所有权标记和 canonical 路径守卫。工作区根、`.dsh-sessions` 及父目录不会被 `Close`/强杀删除。
- 新增 `internal/adapter/dsh/persistence.go`：读取 plain JSONL 与 `.jsonl.zstd` 首行 header、校验 cwd/id、计算 SHA-256，并按 DSH 目录布局进行非破坏性复制。
- 迁移按 session id 先分组再写入目标；同 id 不同摘要、双编码、目标摘要不一致和源文件写入竞争均不覆盖目标，源文件始终保留。无效 artifact 计入 `Unsupported`，不会被当作事实。
- `session-query.db`、WAL/SHM 不复制；新根由 DSH 自行重建派生索引。
- 通用 Provider 真值回归已纳入 DSH 未配置分支：清空 DSH bin/config 时 Detect、Start、Resume 均保持 fail-closed；有效 ACP 握手的 Resume native 由 DSH 专属契约覆盖。

## 3. P1：Resume、回放与句柄交接

### 已完成

- 在 `internal/adapter/spi.go` 增加可选 `ResumeStreamingAdapter` 与 `ReplayCompletionHandle`；runtime handle 不进入 Relay `ResumeResult` 或 local state。
- DSH adapter 在发送 `session/load`/`session/resume` 前通过 typed ready callback 交出句柄；Runner 先登记新句柄、启动事件转发，再允许桥发出恢复请求。
- 本机回放状态使用 `pending`、`loading`、`complete`；`ReplayHistory` 只存在于内部 typed 请求，不进入公共命令 JSON。
- `user_message_chunk` 映射为 `user_message`，`agent_message_chunk` 映射为 `message_completed`；回放事件带内部 ordinal，并以 Relay session + ordinal 派生稳定 source key、本机标记和 outbox `event_id`。
- 回放响应到达后先排空事件队列再标记 complete；Daemon 重启后没有旧 handle 时，仍可重新 load/resume 并继续 send。
- 存储 cwd 与调用方 canonical 工作区不一致时返回 `WakeWorkspaceMoved`，不创建半开句柄、不改写历史文件。
- 能力矩阵把 `resume` 标为 `native`；Go 侧尚未真正下发 `set_config_option`，因此 `model_select` 保持 `unsupported`。

## 6. 回滚与证据边界

- 迁移只复制、不删除源文件；回滚可移除目标工作区 `.dsh-sessions` 副本并继续使用 legacy root 清单。
- `Close` 的删除守卫只允许删除本次创建且位于系统临时目录内的探测根；显式取证根和工作区根均不删除。
- 本轮新增报告不得写入 canonical root、DSH session id、消息正文、凭据或完整 stderr；旧的 DSH live prompt 报告已清理，保留的三份本轮报告只含脱敏字段。更早的历史 transport/cache 证据不纳入本轮交付。真实 gate 若命中额度，只能证明路由/模型选择到达 Zen。

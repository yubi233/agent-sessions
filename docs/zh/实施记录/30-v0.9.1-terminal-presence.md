## 3. P1：失效通知与 Relay reaper（2026-09-08，commit c5fa139）

- **PresenceHub 扩展**（`internal/domain/presence.go`）：账号级 presence invalidation 订阅/发布（`PresenceInvalidation` 只含 opaque terminal id + availability + revision，不携带完整 DTO）；发布端只在 revision 真实前进时单次发布；慢订阅者非阻塞丢弃。
- **服务层发布**：hello 恢复转换 / heartbeat `changed=true` 时各发布一次；`DaemonService.Hub` nil 时安全降级（通知只是加速，不是正确性前提，裁决 T4）。
- **有界 reaper**（`internal/domain/presence_reaper.go`）：`SweepOnce` 单次扫描有界（BatchLimit=200）；候选查询只返回「会发生真实转换」的行（持久投影 online 且退出 suspect 窗，或 unknown 且过 offline deadline，避免已转换行饿死批次）；unknown 不降级 legacy status（旧客户端不得把「事实不可确认」误读为离线）；单 Terminal 失败不影响同批；丢唤醒下一 tick 自愈；`Stop` 幂等等待 goroutine 退出。
- **账号 SSE**：下发无 `id` 的 `terminal.presence.changed` 帧（`writeSSEData`）——不进入账号 cursor 空间，Last-Event-ID 回放语义不变；既有 TestP4AccountSSE* 契约保持。
- **进程接线**：`relay.NewServerWithRuntime` 返回 reaper；`apps/relay` 主进程 `go Run()+defer Stop()`；`AGENT_SESSIONS_PRESENCE_REAPER=0` 为 poll-only 回滚开关。

回归：V091-06（`internal/relay/v091_presence_invalidation_test.go`：恢复恰好一次通知帧、无 id、重复心跳零通知、会话帧 cursor 契约不变）；V091-07（`internal/domain/presence_reaper_test.go`：unknown/offline 两段转换、fresh Terminal 隔离、BatchLimit=1 跨 tick 自愈、跳窗直落 offline、Run/Stop 资源释放、订阅计数归零）。web 25/25（账号 SSE 消费语义未变）。

## 4. P2：Flutter 生命周期感知同步（2026-09-08，commit 12e82da）

- **DTO**（`terminal_models.dart`）：消费 availability/presence_revision/last_heartbeat/next_check additive 字段；**彻底移除客户端墙钟 90s stale 二次裁决**（事故根因）；旧 Relay 降级为 status/protocol 派生，不用本地时钟（裁决 T2）。
- **TerminalStatusController 重写**：同步资格 = 认证 + 前台 + 网络非离线 + 活跃 surface；后台/离线/注销/dispose 零新请求，恢复只触发一个去重首拍；single-flight + pending coalescing（手动/失效通知/safety tick/生命周期恢复四路唤醒合并）；auth/surface 双代际丢弃迟到响应（注销清空旧账号投影）；quiet refresh（失败保留最后可信列表、不闪 loading、`isUnreachable` 单独表达）；45-60s jitter safety reconcile。
- **接线**：providers 监听认证相位转发；RuntimeRecoveryBinding 转发前后台/网络；主页与终端状态页 attach/detach surface（dispose 缓存 controller 避免 ref 失效）。
- **回归**（`apps/mobile/test/v091_terminal_sync_test.dart`，fakeAsync 虚拟时钟 + 可挂起 relay fixture）：91 秒前台自动续刷、后台 5 分钟零请求、恢复单首拍、多唤醒合并 ≤2 请求、注销/重挂代际隔离、quiet 失败保留可信投影 + unknown 透传、availability 与本地时钟无关。

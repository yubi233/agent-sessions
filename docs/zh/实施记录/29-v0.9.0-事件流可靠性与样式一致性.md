## 3. P1：同步 scheduler 与生命周期地基（2026-09-07）

### 3.1 C1 提交意图与 202 即时受理锚点

- 新增 `apps/mobile/lib/state/session_turn_runtime.dart`：
  - `TurnSubmissionIntent { newTurn, steer }`——本地提交意图显式传入 controller，不改变 Relay `session.send` wire kind。
  - `SessionActiveTurn`——会话级活动回合运行期状态：单调锚点（`acceptedAt`）、`uxDeadline=锚点+2min`、`continuationDeadline=锚点+60min`（T7 裁决）、`timedOut` 标记。把旧 `_turnInFlight` 同时表达的三件事拆开。
- `SessionController._submitCommand`：Relay 202 返回后、`_awaitCommandReceipt` 与任何快照之前，调用 `_noteSendAcceptedAt202` 原子记录锚点：
  - newTurn：活动回合不存在时新建锚点并清除上一轮超时标记；已存在（幂等重试）时复用原锚点，禁止重复续期。
  - steer：完全继承原锚点与预算；本机无锚点（他端发起/进程重启）时以受理观察时刻建立运行期锚点（observedAt 口径）。
  - 回合在途标记在 202 即置位——composer 主按钮不等首批快照就切换为「中断」。
- `sendMessage(intent:)` 新参数；UI 接线（session_screens.dart）：`SessionSubmitMode.send`→newTurn、`.steer`/`_steerQueuedMessages`→steer、`_sendQueuedMessages`→newTurn。
- `_mergeSnapshot` canonical 终态收口：`completed_turn` 事件或会话进入 idle/stopped/errored 时移除活动回合状态并推进同步代际。本地 UX 超时永远不伪装终态。
- 单调时钟：`monotonicElapsed` 可注入（生产 Stopwatch，测试步进函数）；锚点不跨进程持久化。

### 3.2 C2 三重代际与单航班

- `authGeneration`：认证失效/`resetForAuthBoundary`/dispose 时递增；`syncGeneration[sessionId]`：send/steer/abort 实际提交前与 canonical 终态收口时推进；`selectionGeneration`：沿用并在离开会话页面 surface 时推进（`setSessionSurfaceVisible`）。
- 发送前台轮询循环、后台续轮循环在每次 await 后校验认证/同步代际与会话归属；失配按正常取消静默退出，不显示错误、不改写当前回合任何状态。会话切换不硬取消发送链（C3：切走跳过合并、切回恢复合并），页面级隔离由选择代际在 `_loadSelectedSession` 等选择路径执行。
- `_runSnapshotTurn`：每会话快照刷新单航班门——同会话已有在途刷新时只置 pending，当前请求结束后从已合并 cursor 再补一轮。`recoverSelectedSessionFromCursor`（lifecycle recovery）与 `_bestEffortRefreshAfterCommandFailure` 已接入；L1/L3/SSE 在 P2-P4 陆续接入。

### 3.3 C7 认证边界与 dispose

- `resetForAuthBoundary()`：递增认证代际、清空活动回合/超时标记/cursor/乐观回显/草稿/附件暂存/同步代际、回到列表 loading；不清 token 与密文缓存（调用方负责）。
- providers.dart：`sessionControllerProvider` 监听 `appControllerProvider` 认证相位——回到 signedOut 时先 `resetForAuthBoundary` 再清 token/cache；回到 authenticated 时重新 `initialize()` 重建会话运行期。
- `dispose()`：同步置 `_disposed`、递增认证代际、清空运行期状态；全部 65 处 `notifyListeners` 经 `_notifyListeners()` 守卫——dispose 后任何完成中的 Future 返回不再触碰已释放的 ChangeNotifier。

### 3.5 设计取舍记录

- 发送链的会话隔离不使用选择代际硬取消：V07 既有契约要求「切走再切回后合并恢复」（乐观回显清账依赖它），且 C3 明确「切换会话只取消该选择的 L1 任务、再次打开时从本地 cursor 恢复」。实施口径：逐拍校验会话归属（切走跳过合并）+ 同步/认证代际（steer/abort/新回合/认证切换硬取消）；选择代际继续守护选择路径（`_loadSelectedSession`/`_loadContentKeyAvailability`/恢复）。
- 活动回合终态解除采用精确状态集（idle/stopped/errored + completed_turn 事件），不包含 waitingPermission/waitingQuestion——权限等待回合的服务端事实可能继续（L1 续轮仍需覆盖），与既有 `_turnInFlight` 在权限等待即复位的 UX 语义解耦。

## 4. P2：L1/L2 超时后同步与手动出口（2026-09-07）

### 4.1 L1 降频续轮与 deadline 驱动超时

- `SessionController._runL1DegradedPolling`：选中会话 10 秒一拍（`l1PollInterval`，T7：单会话 0.1 QPS），从已合并 cursor 增量拉快照；canonical 终态移除活动回合后退出；60 分钟 continuation deadline 到期只停止任务并保留超时提示；切换会话/认证切换/新同步代际按正常取消退出；单拍失败下一拍继续（轮询托底）。
- `_evaluateTurnDeadlines`：前台/后台/L1 每拍按单调锚点评估——到达 `acceptedAt+2min` 才置 `turnTimedOut`（只切 UX 表达），窗口耗尽只决定"何时交接 L1"，彻底废除 attempts×interval 推导等待时长（§0 表第 4 行裁决）。
- 状态拆分收尾：`isTurnInFlight` 改为从活动回合表派生（选中会话存在 `SessionActiveTurn` 即在途）。超时不再复位在途标记——中断按钮在超时后仍可用（C1：空草稿仍允许用户中止）；有草稿走既有 queue/steer。abort/kill 作为用户主动终止在受理时移除活动回合。
- 超时清账乐观回显；后台窗口耗尽分支由"停止同步"改为"评估 deadline + 交接 L1"（seq48 事故根因修复点）。

### 4.2 查看结果与事件新鲜度（C3）

- `refreshTurnResult()`：超时横幅「查看结果」手动出口，对选中会话强制一次只读快照同步（服从单航班与代际守卫）；成功只在真实状态/事件到达时清横幅，失败保留横幅并经既有 `errorMessage` 呈现脱敏错误。
- `_lastSnapshotMergedAt`：按会话记录最近一次成功合并事件的客户端墙钟时刻；横幅次级行展示「最近同步 HH:mm:ss」（T5 裁决，不设常驻状态条）。

## 5. P3：L3 quiet reconcile 与完成角标（2026-09-07）

### 5.1 quiet reconcile（C4/T7）

- `SessionController.quietReconcileTick()`：一拍 = 共享 list 对账 + 差异快照调度。前置条件：认证有效（dispose/auth boundary 即退出）、`_quietReconcileActive`（lifecycle recovery 驱动：前台+在线开启，后台/离线关闭）、本地存在已确认活动回合会话（activeTurns 非空或列表含 streaming/waiting 投影）。
- 差异检测：仅比较本地与远端 `status`/`lastSequence`；status 翻转优先于仅序号前进；每拍最多 `quietReconcileBatchSize=4`、并发 `quietReconcileConcurrency=2`（0.04 list QPS + 0.16 snapshot QPS，T7/C4）；未处理项留后续拍。
- 快照回合经 `_runSnapshotTurn` 单航班门——与 L1/SSE/手动拉取天然去重；quiet 路径绝不触碰 `SessionListPhase`，失败静默等下一拍。
- `_listSessionsShared()`：手动 `refreshSessions` 与 quiet tick 共享 listSessions single-flight，并发只发一次。
- lifecycle 接线（lifecycle_recovery_controller）：后台/离线 → `setQuietReconcileActive(false)`（零新请求）；cursor recovery 成功 → 重新激活 + 显式一次首拍（Timer.periodic 首拍在完整 25 秒后，不叠加；恢复快照与首拍快照共享单航班）。

### 5.2 完成角标（C4）

- `_unseenCompletedSessionIds`：认证运行期内存集合，不持久化。置位条件（三要素）：本机曾观察为活动（`_observedActiveSessionIds`，merge 到 streaming 即登记）＋ 快照确认真实 idle 投影（stopped/errored 不算）＋ 非当前选中会话。
- 清除时机：打开并成功合并该会话快照（selectSession）；会话移出列表（refreshSessions 差异）；认证代际结束（resetForAuthBoundary）。
- UI：工作区卡片会话项、工作区详情、最近会话页三处，`Key('session-completion-badge-<id>')` + `Semantics(label: '有新完成结果')`。

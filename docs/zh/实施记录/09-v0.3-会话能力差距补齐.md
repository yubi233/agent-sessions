## 目标、范围与验证口径

本迭代补齐 v0.2 全流程对照发现的六项会话能力差距：permission mode 选择器、goal 文本编辑、usage 深度与 context 警告、Provider 版本/连接提示、duplicate 入口与复制元数据。全部沿用 capability fail-closed 惯例；真实 Provider 的新能力保持 unsupported，不伪造升级。

- 不做语音、社交、付费、Git 写、远程 shell、Happy wire protocol。
- 契约默认 `local_test=true`、`fixture_data=true`。
- 浏览器验收必须 headed Chrome：`real_browser=true`、`headless=false`。
- Flutter 验收仍是 MacBook 可见窗口：`visible_desktop_app=true`、`headless=false`。
- 真实模型 gate 仅当 Adapter 契约变更时复跑。

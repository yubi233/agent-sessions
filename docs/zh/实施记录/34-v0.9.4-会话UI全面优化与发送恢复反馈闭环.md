## 2. 阶段 P1：发送、配置与同步状态闭环（2026-09-19 收口）

### 2.1 消息发送事务（计划 §2.2/§2.4，UI-05/06/07，V094-19/23）

- 新增 `apps/mobile/lib/state/session_send_transaction.dart`：`SessionSendTransaction`
  （submissionId / clientMessageId / draftRevision / 阶段 / 错误分类 / 重试计数 / 取消标记）
  与结构化恢复阶段 `SessionRecoveryStep`（resume→start→resend，上限 1/1）。
- `SessionController.sendMessage` 拆分提交与观察：
  - 提交锁（全局 busy）只覆盖「验证 + 202 受理 + 首批快照」；30s 回执窗口与
    回合轮询转入后台事务观察器 `_observeSendTransaction`（`awaitTurnCompletion=true`
    的直调方保持内联观察，V093 语义不变）；
  - `_submitCommand` 新增 `deferSendObservation` / `onCommandAccepted` / `onTerminal`；
  - 失败回执优先于代际处理（V093-04b 不回退）；LOCAL_STATE_MISSING 触发
    结构化恢复链并换 `#recovered` 幂等键重发（clientMessageId 复用）；
  - 窗口耗尽：有可信进展（流式投影）→ processing；否则 verifying（结果待确认），
    绝不假报成败；
  - 失败事务保留在消息待处理项（正文在内），提供 `retryFailedSend`（新 attempt
    独立幂等键、先核验后补发）与 `consumeFailedSendForEdit`（新草稿非空时拒绝覆盖）；
  - 草稿结算按事务身份：仅当草稿仍是本次提交正文时才清空，观察期新草稿不受
    迟到结算影响；取消（`cancelAutoRecovery`）只阻止尚未提交的自动步骤。

### 2.2 单一展示状态投影（计划 §2.1，UI-01/02）

- 新增 `apps/mobile/lib/state/session_presentation_state.dart`：
  `SessionPresentationState.fromFacts` 纯函数投影——单一主状态按
  硬阻断→回答/审批→恢复/重发→待确认→执行中→会话状态优先级派生；
  角色（可控制/只读）、能力（执行服务可用/不可用）、真实连接三维度独立表达，
  「可操作」泛化承诺与 provider.available＝"已连接"的表述移除；
  stopped 可写时主状态保持「已停止」并以独立行动提示「发送时将恢复」展示。
- `_SessionStatusStrip` 改为消费投影（状态词/图标/角色词/能力 chip 同源），
  `SessionController.buildPresentationState` 是唯一派生入口。

### 2.3 消息级状态（UI-06）

- `ConversationNode` 新增 `deliveryStatus/deliveryDetail`（仅本地事务投影填充；

### 2.4 配置确认与幂等身份（V094-24/25）

- 每控制域（model/effort/permission）确认状态机 `ControlDomainConfirmation`
  （confirming→applied/verifying/unknown/failed）：202 只标"切换中"；命令成功且
  权威投影一致才标已生效（投影滞后有界重查 3 拍）；null/超时进入 unknown
  （不假报成功）；失败保留原值并带原因；域内串行（`_serializedConfigAction`）。
- 每次显式操作独立幂等键（`:act-N` 后缀），A→B→A→B 每次真实变更都到执行端。
- Relay 侧（Go）：`session.model_select` 的会话模型元数据从「受理时乐观写入」
  （internal/httpapi handlers.go，已删除）改为「daemon result succeeded 后权威写入」
  （internal/domain Resolve + `modelFromFixtureCiphertext`）；
  契约测试 `TestModelSelectUpdatesRelaySessionModel` 迁移为完整 daemon 生命周期
  （受理阶段断言 controls 不泄漏请求值 → result succeeded 后投影更新）。

### 2.7 真机冒烟（2026-09-19，d723617）与收敛缺陷修复

按用户指示提前执行实机测试（V094-21 完整旅程之外的定向 smoke）。拓扑与口径见
`e2e-verify/reports/v094-device-smoke/report.json`（real_device=true、headless=false、

500ms 增量快照持续驱动合并直到 canonical 收口（上限 10 分钟；SSE live 时
跳过拉取避免双通道）。发送路径 26 项单测回归全绿（含 V093-02 大 delta
追平收敛、V093-04b 失败回执优先）。

（可发送/执行中/可控制/执行服务可用）、状态槽参与布局不遮正文、

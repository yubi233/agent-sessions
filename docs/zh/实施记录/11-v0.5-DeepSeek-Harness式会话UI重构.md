## 阶段划分

1. **P0：契约冻结与投影测试**：沉淀 `MOBILE-V05-*` 回归矩阵，新增 display-safe projection 与 InputMachine 纯测试。
2. **P1：Resident Shell 与严格 Header**：把详情页收敛为 resident conversation root、严格 header、唯一 scroll owner 和 sticky composer seat。
3. **P2：Chat Nodes 与滚动契约**：以 conversation node projection 替换 raw timeline 渲染，补齐 streaming tail、工具详情、产物文件和消息动作。
4. **P3：Composer State Machine**：用输入状态机替代 `_SessionComposerState` 的局部状态，移除 streaming 后自动 flush。
5. **P4：Composer Chain 接管**：把 question / approval / plan review / subagent read-only 统一收敛到 composer takeover。
6. **P5：Input Trigger、QueueDock 与 Control Seats**：实现 selection-based trigger、显式 QueueDock、Todo/Goal/Model/Permission/Attachment seats。
7. **P6：Trajectory View**：实现按 turn/request/tool/usage 分组的 ledger、搜索、折叠、虚拟行和 inspector。
8. **P7：StatsLine、ContextMeter 与证据回填**：接入真实投影字段、更新项目文档/自动化测试文档并执行 headed 录屏。

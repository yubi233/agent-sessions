### 2.3 埋点 schema v1（冻结，门禁 2 基石）

落点 `apps/mobile/lib/diagnostics/streaming_telemetry.dart`（P1 实现）。事件与字段：

- `stream_first_delta`：`{ts, seq, kind, message_id, latency_ms}`（send 受理 → 首条流式文本帧）；
- `stream_delta`：`{ts, seq, kind, message_id, delta_chars, cumulative_chars, since_last_ms, batch_events}`；
- `stream_completed_reconcile`：`{ts, seq, final_chars, last_stream_chars, consistent}`；
- `stream_poll`（采样）：`{ts, attempt, new_events, fetch_ms}`。

sink：内存 ring buffer **2000** 条上限；导出 `{"schema_version":2, "exported_at", "events":[...]}`（v2，V087-12：stream_delta 增加可选 `block` 字段——真实桥按 step 分多条消息，sink 以累计回退检测新块；缺失视为 0，向后兼容）。**审计红线：任何字段不得含消息正文/工具原文/内部路径**；V087-03 以注入正文子串零命中断言。

## 3. P1：埋点先行（2026-09-05 交付）

**交付物**（V087-02/03/10 全部 passed）：

1. **埋点 sink** `apps/mobile/lib/diagnostics/streaming_telemetry.dart`：4 类事件（`stream_first_delta`/`stream_delta`/`stream_completed_reconcile`/`stream_poll`）、ring buffer 2000、`export()` 输出 schema v1。语义要点：
   - **基线外帧忽略**：`sendAcceptedAt == null` 时（历史加载、非本端受理路径）帧不进埋点、不建帧状态，但 seq 高水位照常推进——防止回合内全量快照重解析把历史帧当新 delta；
   - **高水位去重**：会话级 seq 单调高水位，重复投递/全量重解析零重复埋点；
   - **回合边界**：`observeSendAccepted` 清上一回合帧状态（防跨回合长度串账）；
   - **审计红线**：字段白名单（seq/kind/message_id/长度/时间差），V087-03 以逐型键集精确匹配 + 注入正文子串零命中双重锁定。

3. **daemon 回合流式摘要** `internal/daemon/turn_stream_summary.go`：在 `recordEventResult` 事件泵单点内累计 `message_delta`/`message_thought_delta`（rune 计数），`turn_completed`/`session_aborted` 终态输出至多一条 Info（delta_events/delta_chars/stream_span_ms/terminal）；`fwdCtx` 回收路径静默丢弃半途计数；`turn_started` 回合边界重置；开关 `AGENT_SESSIONS_TURN_STREAM_SUMMARY=0` 关闭。

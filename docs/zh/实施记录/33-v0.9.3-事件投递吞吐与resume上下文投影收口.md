## 2. P0：V093-01 定向归因（commit `cee8800`）

- **方法**：`internal/daemon/v093_event_throughput_diagnostic_test.go`（门控 `AGENT_SESSIONS_V093_ATTRIB=1`）以假 Relay 模拟 RTT，入箱 16779 条 delta 后排空；同机跑零 RTT 探针分离网络成本与本地落账成本。**先打埋点再看数字**：`flushEvents` 摘要日志（uploaded/elapsed_ms/pending_remaining/rate_per_sec，≥200 条或 ≥1s 升 Info）+ `Store.PendingRelayEventCount`。
- **量化结论**：串行逐条上传在 30ms RTT 下 536.5s / 31 条/秒（积压半衰期 266.6s），与 R18 云端实测 16 条/秒同量级（云端 RTT 更高）；零 RTT 探针 6968 条/秒——本地落账不是瓶颈。
- **修复方向**：批量上传把万级追平从「N×RTT」降为「⌈N/200⌉×RTT」。
- **T3 阈值冻结**：万级 delta 回合结束后出箱 30s 内归零；`turn.completed` 入箱后 10s 内投递；UI 终态到达后 5s 内收敛。
- 报告：`e2e-verify/reports/V093-ATTRIB/v093-throughput-baseline-20260918T000700Z.json`（口径 local_test=true、fixture_data=true、headless=false）。

## 3. P1：V093-02 批量上传 + V093-03 投影修复（commit `6f3a19a` / `af59c49`）

### 3.1 批量上传（V093-02）

- **契约**：OpenAPI `POST /v1/daemon/events/batch`（`DaemonEventBatchUploadRequest/Response`，maxItems=200）→ 三语言生成物同步。
- **Relay 端**：`domain.UploadEventBatch` 单事务按数组顺序落库——event_seq 批内严格递增、重复投递整批幂等、任一事件非法整批原子回滚；`UploadEvent` 重构为其 len=1 特例（`appendDaemonEventInTx` 单点共享，两条入口语义永不分叉）。handler 一次签名覆盖整批、按会话发布失效通知、413 上限 4MB。
- **Daemon 端**：`RelayClient.UploadEvents`（回执与请求等长校验）+ `Store.MarkRelayEventsDelivered`（单事务批量标记，摊薄 autocommit fsync）+ `flushEvents` 按「条数 200 + 字节 1MB」分块。回滚开关 `AGENT_SESSIONS_DAEMON_EVENT_BATCH_SIZE=1` 完整还原逐条路径；批量级 4xx 回退逐条隔离毒丸（`RELAY_REJECTED_PERMANENT` 语义不变）；瞬态失败整批退避。
- **冻结契约复核**（迭代计划 §3.2）：顺序（出箱排序贯穿数组与落库）、幂等（receipt 查重同路径）、终态语义（后到状态覆盖）、E2EE 形状（envelope 原样透传）均未放松。
- **达标门**：`TestV093EventThroughputBatched`——10000 条 delta @30ms RTT **1702ms 追平**（50 次批量请求、0 次单条），较逐条基线（同规模约 320s）提速约 190 倍，远优于 T3 的 30s。
- **回归**：`internal/relay/v093_event_batch_contract_test.go`（顺序+幂等+终态投影/原子拒绝/超限与空批）+ `internal/daemon/v093_event_batch_flush_test.go`（分块顺序/字节分块/整批 4xx 回退毒丸隔离/瞬态退避/回滚开关）。

### 3.2 resume 上下文投影（V093-03，commit `af59c49` + 桥仓独立 commit）

- **根因**：桥 `replaySession` 重放全部 user/message 事件（含 skill 插件注入的 `source.kind=skill-catalog` 模型侧上下文）为 `user_message_chunk`；Go mapper 无过滤映射为 `EventUserMessage`。live turn 本就不转发 user 消息，注入只在 resume 回放路径泄漏——与 R18 实测（时间线出现「你 | <system-reminder>」节点）完全吻合。
- **桥侧**（deepseek-harness，独立仓库 commit）：`replaySession` 按持久化 `source.kind` 过滤（防御性读取，不按文本匹配；模型上下文不变，仅过滤回放投影）；`tests/replay-skill-catalog.spec.ts` 回归；`pnpm build:lib:host` 重建运行时 lib 后 dsh-v084-overlay 真实桥复跑全绿、`TestLiveBridgeLifecycle` passed（版本门 wire 版本仍 0.0.1，无需登记变更）。
- **Go 侧纵深**：`mapper.go` 对 user_message_chunk 按 `<system-reminder>` 固定前缀丢弃并计数（兜底未升级旧桥）；`TestMapSessionUpdateDropsSkillCatalogInjection` 钉扎注入帧丢弃与普通正文不误伤。

## 4. P2：F4 客户端自动恢复加固 + V093-04 真机（commit `7189581`）

- **真机链路环境说明**：本轮真机使用本地拓扑（restart.sh Relay + go run daemon + USB 真机 + adb reverse tcp:8787），应用自 HEAD debug 构建。环境曾出现两次非产品问题并如实记录：① 失败的 `restart.sh restart --no-relay` 清理副作用导致 relay 进程退出、后续 `relayctl.sh up` 默认指向 `data/relay.db` 造成 daemon hello 401（处置：`RELAY_DB_PATH=.task/restart/relay.db` 重启 relay + 以配对 token 重启 daemon）；② 恢复码签发使用 `e2e-verify/helpers/issue-recovery-code`（生产同源域路径，代码只落 600 文件）。

- **客户端加固**（`session_controller.dart`）：
  - `sendReceiptPollAttempts`（默认 120×250ms=30s）独立于 `receiptPollAttempts`（24×250ms=6s）——R18 云端「回执晚到→受理即确认→恢复永不触发」的时序缺口由此关闭；
  - T4 冻结：恢复全程 `recoveryNotice` 可见提示（Chat 视图 `session-recovery-notice-row`，优先于超时/生成中状态条），恢复结束即清除；重试上限钉死 1 次（`#recovered` 幂等键），再失败按真实故障浮出。
- **回归**：`session_send_auto_start_test.dart` 7/7（新增延迟回执触发自动恢复、恢复可见性两用例）；受影响 43 项回归全绿。
- **真机 V093-04**（本地拓扑，real_device=true、headless=false、真实模型）：
  - 拓扑：Mac restart.sh Relay + go run daemon + 真机 23113RKC6C（USB + adb reverse），应用自 HEAD 构建；

- **录屏演示与追加缺陷修复（V093-04b，按工作流 §7 真实模型演示要求补做）**：
  - 录屏产物：`e2e-verify/screencasts/20260918-0329-v093-04-recovery/`（take1 缺陷形态对照 103.8s + take3 修复后主录屏 113.9s + 关键帧 + manifest）；

## 7. 遗留与残余风险

- **熄屏-离线门控观察项**：真机熄屏期间 connectivity 事件使恢复控制器进入 offline 门控（等待网络横幅），期间 SSE/轮询停拍；点亮后依赖 connectivity 变化事件复位，否则终态收敛延迟。V093-04 主断言不受影响（发送时刻在线即恢复链路工作），但「熄屏后回归前台的自愈体验」建议后续迭代单独立项观察。
- **云端形态 V093-04 复测**：受云端 daemon 重启窗口约束未执行；本地拓扑结论与 V092-10(local) 同口径，云端复测继续作为后续受控窗口任务。
- **桥仓联动**：F3 修复落在 deepseek-harness 仓库（独立 commit），部署侧桥 checkout 更新需随发版流程同步（Agent Sessions 侧已具备 Go mapper 防御兜底，未升级旧桥亦不回退投影正确性）。

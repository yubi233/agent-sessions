## P2：进程所有权与 Resume 定级回归

- 新增 `internal/adapter/dsh/process_test.go` 六用例（纯 Go，`/bin/sh` 子进程，无 node 依赖，包总时长 <1s）：
  1. ForceKill 终止整个进程组（含 sleep 孙进程，pid 探活）且重复强杀幂等；
  2. Dispose 宽限路径：EOF 自行退出、未走强杀；
  3. 忽略 EOF 的子进程在宽限期后升级 SIGKILL（三重断言：文案 + exitCode==-1 + 耗时≥宽限）；
  4. Dispose 后 Events() 通道最终关闭；
  5. stderr 环形缓冲封顶与脱敏（超长行截断致伪造密钥整体不可见；64 行×512B 封顶实测生效）；
  6. Resume 恒 `WakeUnsupported` 且不 spawn 子进程（六态集合校验、InstanceID 恒空）。
- 产品代码最小重构：`bridge.go` 宽限期改为可注入字段（缺省 10s 不变），供时序回归压缩到毫秒级。
- 验证：gofmt 空 / vet 通过 / build 通过 / `go test ./internal/adapter/dsh/... -count=1` ok(0.542s)，连跑 3 次稳定。

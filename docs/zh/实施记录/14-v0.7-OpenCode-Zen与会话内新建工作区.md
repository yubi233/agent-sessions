### P2 实施与验证

- Daemon 通过 `ResolveWorkspaceRoot` 在启动时 fail-closed 校验授权根；`WorkspaceManager.Create` 只接受共享名称规则，在授权根直接子级 mkdir/复用，新增目录执行 `git init --quiet`，并将 opaque workspace ID 与 canonical root 写入本机确认表。已存在的非目录、非 Git 根、符号链接逃逸和控制字符均拒绝；不会删除或覆盖用户已有目录。
- Relay `WorkspaceService` 以账号+规范化名称生成稳定 workspace/project ID 和幂等 scope，要求 Android owner/write 身份、在线 Terminal 以及 `workspace_create` capability。命令使用 `lease_epoch=0`，普通 session result 不接收；`/v1/daemon/commands/:id/workspace-result` 收到成功回执后才在同一事务登记 Workspace。客户端 create/status 响应和 workspace 列表只投影白名单字段，不包含 `canonical_root`。
- Flutter `SessionController.createWorkspaceWithName` 只向真实 Relay 提交名称，pending 时有限轮询并保持单飞；`NewSessionScreen` 对名称做 Form 校验、展示“正在创建工作区…”状态，成功后自动填充 workspace ID。真实 HTTP 模式不暴露 Host 目录选择，fixture 目录 flow 仅保留历史本地回归兼容。

### 本地真实使用缺陷修复（2026-08-29 下午，restart.sh 栈）

真实使用中连出四个缺陷，全部修复并带根因层回归：

1. **owner access token 15 分钟过期后 App 报「设备连接已失效」**：owner TTL 15 分钟（terminal 24 小时），App 只在启动恢复路径刷新，请求层 401 直接收敛为连接失效。修复：`http_relay_repository` 401 时用 refresh token 刷新一次并重放（并发去重共享一次在途刷新），新增 `writeTokens` 钩子把旋转后的 refresh token 立即持久化，防止 reuse 撤销整族令牌。
2. **restart.sh 启动失败 `migration 61: duplicate column name`**：存量 dev 库经历史路径已具备 `archived_at_unix_ms`/`last_activity_at_unix_ms` 列而 `schema_migrations` 停在 60，新增的编号迁移 61/62 撞重复列。修复：`migrateWith` 对 `ALTER TABLE … ADD COLUMN` 形态的迁移做存在性对账，列已存在则登记版本后跳过；不删库、不丢数据。
3. **发消息后无回复、无生成状态、也无报错（三层叠加缺陷）**：App `sendMessage` 密文不带 composer 选中的模型；daemon 发送路径也不回退会话已选模型 → opencode 收到空模型回退到它的配置默认（付费订阅条目 `opencode-go/ox-alpha-free`，不在 catalog）→ `ProviderModelNotFoundError` 异步失败；适配器的 `errorProps.Error` 声明为 string 而真实 `session.error` 是 `{name, data:{message}}` 对象，反序列化失败把错误整个吞掉，最后还照发 `turn.completed(idle)` 假装成功。修复：App 发送密文携带 `controls.model ?? defaultModel`；daemon 发送按「密文随行 > 持久化选择 > handle 现值」应用模型；适配器新增 `SetModel`（spi 可选接口 `ModelOverrideHandle`）与目录兜底（空模型只能回退 catalog 已确认条目，绝不落到服务端默认）；`errorProps` 兼容字符串与对象两种形状并提取 `data.message`。实证方式：隔离 opencode serve + SSE 抓取确认 `session.error` 事件真实形状。
4. 回归：Go 侧新增 5 项（空模型目录兜底 ×2、存量会话模型应用、嵌套错误可见性、迁移列对账）+ Flutter 侧 3 项（401 刷新重放 ×2、发送密文携带模型）；`go test ./internal/... -count=1` 全过、`flutter analyze` 全库无问题。端到端验证：restart.sh 栈上不带模型的发送正确回退会话模型并拿到真实回复（`message.completed` 文本进入时间线，命令 succeeded）。

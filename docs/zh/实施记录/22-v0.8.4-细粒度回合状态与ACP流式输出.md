## 关键设计裁决（ADR-015 落地）

1. **thinking/streaming 交错歧义**：首个 text chunk 之后 phase 进入 `streaming`，后续 thought delta 不回退（单向转换），桥与 Go 双实现一致。
2. **加入进行中回合**：桥重启后首帧允许是任意相位（权威投影），后续帧才受转换表约束——避免真实重启场景被严格校验误杀。
3. **消息身份**：delta 与 committed 共用 `t<turn>s<step>` 等价身份（messageId 缺失时），completed 另携 `provider_message_id` 旁证；客户端按身份整体替换。
4. **回滚开关双向安全**：桥不声明扩展→无增量/thought/phase 帧；Go `AGENT_SESSIONS_DSH_STREAMING=off`→不声明且不解析 meta；`_meta` 是 ACP 标准扩展点，旧客户端必须忽略，四组合均回退 v0.8.3 语义。
5. **queued→completed 合法**：旧桥无投影时 adapter 以 prompt 响应直接合成权威终态，客户端不悬挂；桥已投影时被终态 fence/自环去重。

## 残余风险与边界（如实记录）

- 桥（deepseek-harness/packages/acp/acp/src/index.ts）当前只实现 initialize/new/load/resume/set_config_option/prompt/cancel；
  session/close、session/list、session/delete、session/fork、session/set_mode、图像附件、additionalDirectories
  均无 handler → Go/Relay 侧按动态 gate 保持条件式 unsupported（计划 §2 决策列与 §3.2 成功标准 8）。
- 生产 approval.policy=never：request_permission 不会真实到达；ask fixture 场景由假桥契约覆盖。
- 真实模型路径未验证；真实 gate 需单独授权。
- Web 为只读架构（ChatView 未挂载路由）：会话消息正文只经密文 envelope 元数据展示（event_type 序列），
  工具载荷的正文级渲染验证落在移动端（localdev_encoder 契约 + Flutter widget 测试）；
  P3a headed suite 验证的是工具事件经 Relay 全链路的事件时间线可见性，不渲染正文。
